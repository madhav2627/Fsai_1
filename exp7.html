Aim

Implement JWT Authentication

Theory

Modern AI web applications combine machine learning models with web frameworks. Flask is commonly used as a lightweight backend to serve machine learning predictions. Frontend applications communicate with the backend using HTTP requests.

Software Requirements

  • Python 3.10+
  • Flask
  • MongoDB / scikit-learn / JS libraries
  • VS Code
  • Browser

Procedure

1. Create a project directory.
2. Create a Python virtual environment.
3. Install required packages.
4. Write the Flask application code.
5. Run the Flask server.
6. Test the program in the browser or Postman.

Example Code

from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route("/")
def home():
    return "AI Lab Experiment Running"

@app.route("/predict", methods=["POST"])
def predict():
    data = request.json
    numbers = data["numbers"]
    result = sum(numbers)
    return jsonify({"result": result})

if __name__ == "__main__":
    app.run(debug=True)
